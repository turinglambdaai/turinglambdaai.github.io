# 公开主页、文档与截图保鲜规范

[English](PUBLIC-PRESENTATION.md) · **简体中文**

状态：2026-10-27 起采用的审查与变更规范。本规范补充[产品交付标准](PRODUCT-STANDARD.md)、[主页规划](HOME-PAGE-PLAN.md)和[文档语言政策](DOCUMENTATION-LANGUAGES.zh-CN.md)。产品真实能力、使用指南、发布产物和协议仍由对应产品仓库负责。采用规范**不代表**产品已验收、历史内容已全部翻译或线上部署已核实。

## 各页面的职责

| 入口 | 用户的任务 | 内容边界 |
| --- | --- | --- |
| `jrtx.site` | 快速找到匹配用途、实际可用的产品 | 产品目录及准确的预览/实验状态 |
| `<product>.jrtx.site` | 理解能解决什么问题，找到安装、第一次成功、隐私和支持 | 以任务结果为中心的简短介绍，依据真实发布和使用手册 |
| 产品 `README.md` / `README.zh-CN.md` | 判断是否适合、快速运行或开发 | 当前支持范围、最小可验证示例、系统要求、文档、许可证与反馈 |
| 产品用户手册 | 完成任务、数据恢复、排障与安全升级 | 可搜索的文字和经过验证的命令，截图按需提供 |
| 更新日志/发布页 | 判断能否以及如何升级 | 版本、系统架构、产物、限制、校验/签名和迁移事项 |

**不要让截图承担主要教程职责。** 应提供可搜索的操作文字、可复制的命令、键盘替代路径、预期结果、失败和恢复方法。先讲真实任务的“输入 → 操作 → 可观察结果”，再介绍功能。产品的真实成熟度比视觉精致更重要。

## 单一事实来源

- **一个权威、多处摘要。** 已测试的产品代码/规格和真实发行产物决定功能、OS/CPU、安装包名称、启动流程和更新能力；使用手册解释存储、备份与恢复；当前已批准且确实开放的商业条款决定价格。其他页面只写必要摘要并链接源头。
- **分清已交付、实验和规划。** Roadmap、通过 CI 的后端或模拟器不等于原生 GUI、硬件精度、已支持平台、开放收款或已完成更新功能。不要放未验证的直接下载地址、数字预告价格、虚构用户评价或绝对化隐私宣称。
- **区分源码与线上部署。** 搜索缓存可能在仓库更新后仍展示旧内容。每次改站点都记录网页源码 commit、实际网址的部署核查结果和对应产品发布 tag/产物。查不到线上结果应标记“未验证”，不能声称已经修好。
- **中英文同步。** 功能状态、示例、数值、下载意图、平台、限制、隐私和交易状态必须一致。技术标识和命令保持原样；未翻译应明确登记。
- **按类型处理。** 商业产品重在任务/可信度/安装；基础库重在可运行最小示例/API/兼容性；内容归档重在来源、更新与勘误。不要把第三方镜像或归档仓库强行改成销售型模板。

## 截图、动画和演示规范

截图是**有版本范围的产品证据**，不是长期稳定的说明接口。

1. 功能说明、价格与状态、CLI 示例、快捷键、导航文字尽量使用真正的 HTML/文字。只有空间布局和视觉操作才使用图片。CSS/HTML 模拟界面必须标为“示意”，不得冒充打包软件的真实截图。
2. 从已验证的发行版本或候选构建中截取可复现状态。使用合成示例数据，删除账号密钥、私有文档和本机敏感路径，保留原图和适当处理后的版本。
3. 在图片旁或受版本管理的 manifest 中记录：文件路径、产品名、应用版本、完整源码 SHA、可验证构建/发布依据、平台及系统版本、主题、界面状态、拍摄日期、真实截图或示意图类型，以及中英文替代文字。字段示例见[英文规范](PUBLIC-PRESENTATION.md#screenshot-animation-and-demonstration-contract)；这不是已经存在某张图片的声明。
4. 通常一张有价值的真实首页图加少数任务细节图即可。使用尺寸合适的 WebP/AVIF 或 PNG，非首屏图片延迟加载，保留有意义的 alt，必要时标注平台/版本。不要把大段文字、命令和价格做进图片。
5. UI 布局、标签、首启路径或系统宿主变化时，**触发截图复核，而不是无差别重截**。对照当前软件：更新、标记历史版本或删除旧图。不能用新版本截图覆盖旧版发布的证据。
6. 各平台遵守自己的原生设计。macOS 的截图不能代表 Windows 界面；差异用文字说明，必要时补充对应平台图片。读者不依赖图片仍须能完成任务。

## 随版本执行的小型检查表

- [ ] 记录源码 SHA、真实发布 tag 和实际支持的下载产物；对未支持的平台直说。
- [ ] 在干净安装或隔离配置中验证一次有用任务，把可复制命令及预期输出写成文字。
- [ ] 核对产品站点、README 中英文、手册中英文、GitHub About 和 jrtx.site 目录卡片，尤其是平台/架构、更新、CLI 包装、数据同步与备份、价格、安全声明。
- [ ] 核对截图与当前构建，保留版本、系统、来源、alt 及历史内容说明。
- [ ] 检查链接/资源、中英文导航、移动端与桌面端、200% 缩放、键盘焦点、减少动效和图片替代文字；静态脚本不能证明产品功能或视觉正确。
- [ ] 比对实际线上页面和预计部署 SHA，保留回滚版本，并在产品 Issue 中记录证据和未完成项目。
