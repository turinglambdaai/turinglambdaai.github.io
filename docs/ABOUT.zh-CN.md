# 关于 jrtx.site

[English](ABOUT.md) · **简体中文**

jrtx.site 是独立开发产品、写作与开源库的展示入口。它不办理统一注册、激活或支付；各产品的实际可用范围与数据处理方式以对应用户文档为准。多数应用仍在开发预览阶段。

通过用途分类选择工具，进入产品主页后阅读安装与已知限制。库用户从 Rivet、Glaze、Keel、Permit、Commerce 各自 README 的英文或中文入门开始。中文书籍与第三方归档保留原文语言，不表示已有完整英文内容。

页面使用浏览器存储记住语言和主题，并加载百度统计脚本；不能将本站描述为没有第三方统计。产品链接、GitHub、微信及外部内容具有各自的数据政策。清除浏览器站点数据可重置本地偏好。

本站不展示内部目标定价或投资规划作为用户报价。尚未开放的托管或购买能力不能从产品卡片推断为已可用。反馈产品问题请进入该产品 Issues；本站坏链接、文案或无障碍问题可通过[本站 Issues](https://github.com/turlamai/turinglambdaai.github.io/issues)报告，提交前移除私人信息。
